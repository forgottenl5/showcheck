# Contributing

Welcome, via GitHub Issues or forgotteni5.lab@gmail.com:
- **Issues:** bugs, unclear reports, file formats we read wrongly.
- **Results:** what ShowCheck caught on your show, or what it missed.
- **False alarms:** a check that FAILed or WARNed when nothing was wrong.

Please anonymize any show file before you attach it (`python -m showcheck.cli anonymize`, see README).

**Code pull requests are not accepted for now**, to keep the licensing clean (ShowCheck is also offered under
commercial licences). Describing a fix in an issue is very welcome.
